TSI Trade — setup notes

Files:
- index.html: standalone responsive dashboard.
- supabase_setup.sql: creates the account_config table and row-level security policies.

1. Supabase
   - Open your Supabase project SQL Editor.
   - Run supabase_setup.sql.
   - Open Project Settings > API (or Connect) and copy the PUBLIC anon/publishable key.
   - In index.html, replace YOUR_SUPABASE_PUBLIC_ANON_KEY with that public key.
   - Do NOT place a service_role/secret key in index.html.

2. Set capital
   - Create a user through the website's Create account button and verify email if enabled.
   - In Supabase Table Editor > account_config, find that user's user_id and set initial_capital to the project amount (e.g. 1000.00).
   - The website reads that amount after login. The client cannot update capital because no UPDATE policy is granted.

3. Publish
   - Upload index.html as the site's index.html to a new GitHub repository or separate GitHub Pages project.
   - Supabase URL is already set to the project URL previously provided.
   - The chart uses TradingView's public embedded chart widget.

Project limitations:
- The chart is sourced from TradingView; chart availability/symbol support may vary.
- Bot entries/exits and pip/P&L numbers are simulated and generated by the browser; they are not actual market quotes, broker orders, or verified trading returns.
- Simulation state is in the current browser session and resets on refresh. This starter version does not persist trade history.
- 15% is a target display/stop condition, not a promised or guaranteed return.
